# Folder: videos
Folder ini untuk menyimpan video-video website Pesantren An-Nahl.

## Struktur yang disarankan:
```
videos/
├── profil/         → Video profil pesantren
├── kegiatan/       → Video dokumentasi kegiatan
├── wisuda/         → Video wisuda tahfidz
├── dakwah/         → Video ceramah/kajian
└── thumbnails/     → Thumbnail cover video
```

## Format yang direkomendasikan:
- **MP4** (H.264 codec, paling kompatibel)
- **WebM** (alternatif, ukuran lebih kecil)

## Tips:
- Resolusi maksimal: **1080p (1920x1080)**
- Bitrate: **2-5 Mbps** untuk keseimbangan kualitas & ukuran
- Untuk video berat, gunakan **YouTube embed** lalu simpan thumbnail-nya di sini
- Tambahkan poster/thumbnail di folder `thumbnails/` untuk lazy loading
