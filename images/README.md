# Folder: images
Folder ini untuk menyimpan gambar-gambar website Pesantren An-Nahl.

## Struktur yang disarankan:
```
images/
├── hero/           → Gambar hero section (1920x1080px, landscape)
├── program/        → Gambar program pesantren
├── berita/         → Gambar artikel berita
├── galeri/         → Foto dokumentasi kegiatan
├── pengasuh/       → Foto profil kyai/ustadz
├── fasilitas/      → Foto gedung, asrama, dll
└── logo/           → Logo dan favicon
```

## Format yang direkomendasikan:
- **WebP** (utama, ukuran kecil)
- **JPG** (fallback, kompresi 80%)
- **PNG** (untuk logo/transparan)
- **SVG** (untuk ikon/logo vektor)

## Ukuran yang disarankan:
| Kegunaan       | Ukuran          |
|----------------|-----------------|
| Hero           | 1920 x 1080 px  |
| Thumbnail      | 600 x 400 px    |
| Galeri         | 800 x 600 px    |
| Profile        | 400 x 400 px    |
| Logo           | 200 x 200 px    |
